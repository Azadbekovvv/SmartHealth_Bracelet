# SmartHealth Bracelet

Веб-платформа для мониторинга состояния здоровья с использованием умных браслетов.

## О проекте

SmartHealth Bracelet — это система для сбора, отслеживания и анализа показателей здоровья, получаемых с помощью умных браслетов.

Платформа позволяет пользователям контролировать состояние здоровья, просматривать историю измерений, настраивать уведомления и отслеживать местоположение подключённых устройств.

## Основные возможности

- **Аутентификация** — регистрация и авторизация пользователей с использованием JWT.
- **Управление браслетами** — подключение и управление умными браслетами.
- **Мониторинг здоровья** — сбор и отображение показателей сердечного ритма и уровня кислорода в крови (SpO₂).
- **Правила оповещений** — настройка индивидуальных пороговых значений показателей здоровья.
- **Уведомления** — автоматическое создание уведомлений при превышении заданных показателей.
- **Отслеживание местоположения** — получение и просмотр геолокации браслетов.
- **Геозоны (Geofencing)** — настройка географических границ и отслеживание перемещений устройств.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd SmartHealth_Bracelet
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python3 -m pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта:

```env
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=smarthealth
JWT_SECRET=your_secure_secret_key
```

Укажите собственные параметры подключения к базе данных и секретный ключ.

### 5. Запуск приложения

```bash
uvicorn backend.main:app --reload
```

После запуска документация API будет доступна по адресам:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Тестирование

Для запуска автоматизированных тестов выполните:

```bash
python3 -m pytest -v
```

Для запуска тестов с проверкой покрытия кода:

```bash
python3 -m pytest --cov=backend --cov-report=term-missing
```
